# ProServer — برو سيرفر

موقع شركة برو سيرفر لأعمال تأسيس وصيانة الكهرباء والسباكة.

- `index.html` + `assets/` — نسخة ثابتة من الموقع (تُعرض على GitHub Pages).
- `wordpress-theme/` — قالب ووردبريس الكامل.
- `proserver-theme.zip` — القالب جاهز للرفع: ووردبريس ← المظهر ← قوالب ← أضف جديد ← رفع قالب.

بيانات التواصل والأرقام تُعدّل في ووردبريس من: المظهر ← تخصيص ← «بيانات برو سيرفر».
